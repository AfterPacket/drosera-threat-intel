MIRAI_OHSHIT

2026-08-07
SHA-256 8b1a2fb6b358484b7769aeeb63209f2b277d91b5015cf28ce471a67e0ef83d28

Multi-architecture IoT botnet staged entirely from 94.154.43.123, with the full chain recovered. A 104-byte fetcher written to /tmp/.p over telnet pulls ohshit.sh, which loops 16 architectures, cats each payload into a file named WTF, and executes it. Seven of the sixteen builds were captured; the doubled slash in //bot.<arch> makes a reliable detection string. Domain indicators are incomplete: the ELF payloads contain domain strings that could not be extracted, so this family is not IP-only despite the loader chain being so.

BOTKILL_PROCWIPE

2026-08-04
SHA-256 2733d565138186645b2ff2485f88cfdaee2a1cf2cd3af1306273fc0f6191a58c

Not malware — competitor-removal scripts written to /home/.k by an operator clearing rivals off a box it wants to keep. One kills any process whose /proc/$pid/exe ends in (deleted), the standard tell of a self-deleting bot; the other greps cmdlines specifically for dvrHelper — the exact payload name used by MIRAI_LOADER above. A host with /home/.k has two intruders, not one.
